# Verde Café

Site de uma página feito com HTML, CSS e JavaScript.

## Estrutura

```
verde-cafe/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    ├── hero.jpg
    ├── sobre.jpg
    ├── cta.jpg
    └── logo.png
```

## Como abrir

Abra a pasta no VS Code e abra o `index.html` no navegador (ou use a extensão Live Server).
Mantenha a pasta `images` ao lado do `index.html`.
